Add Page Numbers to a PDF

This tool stamps a page number onto every page of your PDF, starting at 1 and counting up sequentially through the document. Numbers are placed in the bottom-right corner of each page — there's currently no option to change the position, starting number, or style, so this is a one-click, no-configuration way to get straightforward sequential numbering.

How it works

  • 1 Upload your PDF
  • 2 Each page is numbered automatically, starting at 1
  • 3 Download the numbered PDF

When to use this

  • Preparing a printed report, thesis, or booklet where readers need to reference specific pages
  • Adding numbering to a document assembled from several merged PDFs
  • Making a long PDF easier to navigate and cite in discussions or reviews

Important considerations

  • Position and style aren't configurable. Numbers always go in the bottom-right corner in a plain numeral style — there's no option for "Page X of Y," Roman numerals, or a different corner.
  • Very small or unusually-sized pages may show the number slightly differently placed relative to standard US Letter/A4 pages, since the numbering is overlaid using a standard page template.
  • Do this after merging, before protecting. If you're combining files with Merge PDF, number the combined result rather than each file separately — and add a password with Protect PDF last, since encrypted PDFs can't be edited further.

Frequently Asked Questions

Can I start numbering from something other than 1, or use "Page X of Y"?

Not currently — every document is numbered sequentially starting at 1, with a plain number and no "of Y" suffix.

Can I choose where on the page the number appears?

Not currently — numbers are placed in the bottom-right corner of every page.

Will this work correctly on non-standard page sizes?

It works on any page size, but the number's exact position is calculated relative to a standard page template, so on unusually small or large custom page sizes it may sit slightly differently than on standard Letter or A4 pages.
