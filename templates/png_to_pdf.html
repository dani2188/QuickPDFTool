PNG to PDF Converter Online

This tool combines one or more PNG images into a single PDF, with each image placed on its own page in the order you select them. PNG is a common choice for screenshots, scanned documents, and graphics with sharp edges or text, so this is a straightforward way to turn a batch of them into one shareable file instead of a folder of loose images.

How to convert PNG to PDF

  • 1 Upload one or more PNG images
  • 2 Click "Convert"
  • 3 Download the PDF file

When to use this

  • Combining several scanned or screenshotted pages into one document
  • Turning a set of PNG graphics or diagrams into a shareable, printable PDF
  • Archiving a batch of images in a single, universally-readable file

Important considerations

  • Transparency doesn't carry over. PNG supports a transparent background, but PDF pages don't — any transparent areas are filled with a solid color in the output.
  • Upload order is page order, and each page matches its source image's own dimensions — there's no cropping or resizing to a uniform page size.
  • No compression is applied, so a batch of large PNGs will produce a correspondingly large PDF. Use Compress PDF afterward if the file needs to be smaller.

Frequently Asked Questions

What happens to transparent areas in my PNG?

They're filled with a solid color, since PDF pages don't support transparency the way PNG does. If you need the transparency preserved for further editing, keep working with the PNG directly.

Can I mix PNG and JPG images in the same PDF?

Yes — use JPG to PDF, which accepts both formats in the same upload.

Does this reduce my file size?

No, images are embedded at their original quality. Run the result through Compress PDF afterward if it needs to be smaller.

Does the order I upload files in matter?

Yes. The first image you select becomes page 1 of the PDF, and the rest follow in the order they were uploaded — check the result and re-upload in the right order if the pages come out reversed or shuffled.
