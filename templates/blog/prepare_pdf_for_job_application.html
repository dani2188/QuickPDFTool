How to Prepare Your Resume PDF for Online Job Applications

Published August 2026

Most job application systems (Applicant Tracking Systems, or ATS) accept a PDF resume, but "accept" and "display correctly" aren't the same thing. Here's a short checklist to run through before you hit submit — most of these take under a minute.

1. Convert from Word to PDF instead of "printing to PDF" from a viewer

If your resume started as a Word document, convert it properly with Word to PDF rather than opening it in a random viewer and using a print-to-PDF option, which can shift fonts, spacing, or margins depending on what's installed on that computer. Converting directly from the source file preserves the layout you actually designed.

2. Check the file size against the portal's limit

A huge number of application systems cap uploads at exactly 1MB or 2MB — often without saying so clearly until the upload fails. A text-based resume is almost never naturally that large unless it contains a high-resolution photo or a background graphic. If your file is unexpectedly big, run it through Compress PDF to 1MB before uploading.

3. Name the file like a person will read it

"resume_final_v3(1).pdf" or "Document1.pdf" is a small but real red flag to a recruiter skimming a folder of forty applications. Rename the file to something like FirstName-LastName-Resume.pdf before uploading — this isn't something any tool does automatically, it's just worth doing by hand.

4. Double-check what's actually visible on the page

Open the finished PDF and read it exactly as a recruiter would — not just skim it. Check that no text box overlaps another, that a table didn't get cut off at a page break, and that any hyperlinks (email, LinkedIn, portfolio) are the right ones. This step catches more real problems than any tool can.

5. Consider what personal information is on the page

A home address, date of birth, or a national ID number is not required by most employers and adds unnecessary risk if the file is ever forwarded or leaked. If an older resume template includes fields like this and you want to remove them without reformatting the whole document, our Redact PDF tool can permanently black out a specific line without touching anything else on the page.

6. Keep a copy of exactly what you sent

Save the final PDF you actually uploaded, not just the Word source. If you get a call back weeks later, you'll want to know precisely which version of your resume — and which job description wording, if you tailored it — that employer saw.

Frequently Asked Questions

Will an ATS actually read text correctly from a PDF resume?

Yes, as long as the PDF was created from a real text document (like Word) rather than scanned or exported as flattened images. Text created digitally remains selectable and machine-readable inside the PDF.

Should I compress my resume even if it's already small?

No need — compression only matters if you're bumping against an upload limit. A well-formatted text-based resume is typically well under 1MB already.

Is it ever better to submit a Word file instead of a PDF?

Only if the job posting specifically asks for one. PDF is the safer default because it displays identically everywhere, while a Word file can reflow or shift fonts depending on the reader's software and installed fonts.
