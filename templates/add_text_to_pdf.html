Add Text to PDF lets you type a note, a date, a label, or a short line of text directly onto a PDF page without opening desktop software. Upload a PDF, drag the text box to wherever it needs to sit on the page, then apply it and download the edited file. It's aimed at quick, one-off edits — a signature date, a stamp, a filled-in blank on a form — not full document authoring.

How it works

  • 1 Upload your PDF
  • 2 A preview of the first page appears with an editable text box
  • 3 Type your text, drag it to the right spot, and set font size and color
  • 4 Click Apply Text to generate the edited PDF
  • 5 Download the file with your text embedded

When to use this tool

Filling in a blank: Add a name, date, or reference number to a form that doesn't have fillable fields.

Quick annotations: Drop a short note or instruction onto a page before sending it along.

Labeling scanned pages: Add a page title or category label to a scanned document.

Important considerations

Text is added to the first page only. If you need text on multiple pages, you'll need to run the file through the tool once per page (export each page separately with Split PDF first, add text, then merge them back together).

There's a single font available, with adjustable size and color — this isn't a full text editor, so it won't match an existing font already used in the document.

Frequently Asked Questions

Can I add text to every page at once?

Not in one pass — this tool places text on the first page only. For multiple pages, split the PDF, add text to each page individually, then merge the results back together.

Can I change the font?

You can change the size and color of the text, but the font itself is fixed. If you need custom fonts or full formatting control, this tool isn't the right fit.

Will the position be exact?

The text box position is scaled from where you drop it in the preview to the actual PDF page coordinates, so it lands in the same relative spot you placed it.

Is my file kept private?

Yes. Uploaded files and previews are automatically deleted from our server a short time after processing.
