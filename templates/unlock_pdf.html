Remove a Password from a PDF

This tool removes password protection from a PDF and produces a new copy that opens without a password. It decrypts the file using the password you provide — you need to already know the current password. This isn't a password-cracking or recovery tool; it doesn't guess, brute-force, or bypass a password you don't have.

A common legitimate use: you password-protected a PDF yourself (or received one with a password you were given) and now want a version you can open freely — for editing, archiving, or sharing with people who don't need the extra step of entering a password each time.

How to unlock a PDF

  • 1 Upload the protected PDF
  • 2 Enter the password
  • 3 Download the unlocked PDF

When to use this

  • Removing a password you added yourself once it's no longer needed
  • Preparing a protected PDF you own for editing in a tool that can't open encrypted files
  • Sharing a document more freely with people who already have implicit access to its contents

Important considerations

  • You must know the password. If you don't, this tool can't help — it only removes protection using a password you supply, it does not recover or crack unknown passwords.
  • Only unlock files you have the right to unlock. Removing password protection from a document you don't own or weren't authorized to access may violate the document owner's terms or applicable law.
  • The unlocked copy has no protection at all. Anyone with the file can open it — re-share carefully.

Frequently Asked Questions

Can this recover a password I've forgotten?

No. This tool decrypts a PDF using a password you provide — it doesn't guess, crack, or bypass an unknown password. If you've genuinely lost the password, this tool can't recover it.

Will my original protected file be changed?

No. Your upload generates a separate, unprotected copy for download; the original isn't modified. Both files are deleted from our server automatically after processing.

Is it legal to unlock a PDF?

It's fine for files you own or have the right to access, such as removing a password you set yourself. Removing protection from a document you don't have authorization to access is a different matter — use this responsibly.
