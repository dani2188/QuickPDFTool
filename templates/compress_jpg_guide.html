How to Compress a JPG File

{% from "components/byline.html" import byline %} {{ byline(date_published, date_modified) }} {% from "components/open_tool.html" import open_tool %} {{ open_tool("/compress-jpg", "Open the Compress JPG tool") }}

Modern phone cameras produce photos that are several megabytes each — great for print, often too large for email, messaging apps, or a website upload field. Compressing a JPG re-encodes it at a slightly lower quality setting, shrinking the file substantially while keeping it looking clear on screen.

This guide walks through compressing JPGs using our free online tool, which handles a single photo or a whole batch at once.

Step 1 – Open the Compress JPG Tool

Go to our Compress JPG tool. You'll see a file upload area — click to browse or drag and drop your photos directly onto the page.

Step 2 – Select Your Photos

You can select a single JPG or several at once. Each file is compressed individually using the same settings, so a mixed batch of large and small photos all get treated consistently.

Step 3 – Choose a Compression Level

Each level (Low, Medium, High and Extreme) is described on the tool page. Medium is the right default for most photos; only go stronger if the files are still too large.

Step 4 – Download Your Compressed Photos

Click "Compress JPG." When it's done, you'll see the total space saved along with a "Download All (ZIP)" button and an individual download link for each file, showing its before-and-after size.

Tips for Getting the Best Results

  • Photos with lots of fine detail (foliage, fabric texture, crowds) show compression artifacts sooner than simple photos — use a lighter setting for these.
  • Already-compressed JPGs (screenshots re-saved multiple times, or images downloaded from social media) won't shrink much further — they've likely already lost the redundant data a compressor would remove.
  • For screenshots or graphics with text, a PNG usually compresses better than a JPG at equivalent visual quality — JPG's lossy compression tends to blur sharp edges and text.

Common Uses for JPG Compression

Emailing photos: A handful of full-resolution phone photos can easily exceed an attachment limit — compress the batch before sending.

Uploading to a form or portal: Many upload fields cap image file size; compression gets you under the limit without cropping or resizing.

Faster websites: Smaller images mean quicker page loads if you're publishing photos online.

Saving storage: Compressing a large batch of photos before archiving frees up real space on disk or in cloud storage.

When a Batch Doesn't Go as Planned

You need an exact file size and the result is still too big

The tool has four fixed levels and no target-size setting, so it cannot aim for "under 200 KB". Try the next level up from your original, not from a result you already compressed. If Extreme is still too large, the quality setting is not the lever left: the photo has too many pixels, and this tool keeps the pixel dimensions unchanged. Reduce them with the Resize Image tool, or compress the original at a lower resolution, then compare.

The ZIP has fewer photos than you uploaded

Files that are not JPG or JPEG, and files that cannot be read as an image, are skipped without a warning. The result page lists every photo that was processed, so count the rows against what you selected. If nothing in the upload is usable, the tool stops with "No valid JPG files were uploaded."

Two photos share a file name

Photos with the same name, for example IMG_0001.jpg from two different folders, are all kept. In the ZIP the second one becomes IMG_0001 (2).jpg, the third IMG_0001 (3).jpg, and the result page shows the same names. Names that differ only in capital letters count as the same name.

A file name looks different in the ZIP

Letters and digits of any alphabet are kept, so "été.jpg", "фото.jpeg" and "照片.jpg" come back under their own names. In our test, spaces and brackets became underscores ("IMG (2).jpg" came back as "IMG_2.jpg"), folder parts of a path were dropped, and a name with nothing usable in it became "image.jpg". The extension is always .jpg or .jpeg.

One very large photo stops the whole batch

A photo that exceeds the tool's size limit in pixels is not skipped. The tool returns an error and produces no ZIP, even if the other photos were fine. The tool page states the limit. Take the oversized photo out, run the rest, and handle the large one separately.

Frequently Asked Questions

Does compressing make my photo smaller in pixels?

No. The pixel dimensions stay exactly as they were; only the way the picture is stored changes. If an upload form limits width and height as well as file size, resize the photo instead.

Can I run a file through again to shrink it further?

Not usefully. Each pass re-encodes the picture, and in a quick check on one synthetic test image, passes after the first changed the size only marginally. Go back to the original and pick a stronger level instead of stacking passes. We have not measured this on real photos, so treat it as a rule of thumb.

Why might colours look slightly different afterwards?

The tool does not copy the original's embedded colour profile into the compressed file. We confirmed the profile is gone but have not measured how visible the change is, and it depends on the viewer and the original profile. If colour accuracy matters, compare the result against the original before you rely on it.

Are .jpeg and .JPG files accepted too?

Yes. The extension check ignores capital letters and accepts both .jpg and .jpeg.
