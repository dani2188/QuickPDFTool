PDF to PNG: Multi-Page PDFs, File Size and Other Problems

{% from "components/byline.html" import byline %} {{ byline(date_published, date_modified) }} {% from "components/open_tool.html" import open_tool %} {{ open_tool("/pdf-to-png", "Open the PDF to PNG tool") }}

This guide is for when a PDF to PNG conversion doesn't give you what you expected: not all the pages came back, the files are huge, the text looks soft, or you wanted a transparent background. Each section says what is happening and what to do about it, using what we measured on our own PDF to PNG converter. If you only need the basic steps, they are on the converter page.

My PDF has more than 20 pages

The converter turns the first 20 pages into PNG images and ignores the rest. In our test a 25-page PDF produced 20 images, and the results page only said "20 page(s) converted", so the only way to notice is to count. To get the remaining pages, take off the ones you already have and convert again:

  1. Convert the PDF as usual. You get pages 1–20.
  2. Open Delete PDF Pages, upload the same PDF and type the numbers of the pages you already have, separated by commas: 1,2,3 and so on up to 20. A range such as 1-20 is not accepted. Download the shorter PDF.
  3. Convert the shorter PDF. Its first page is page 21 of the original. We tested this with a 45-page PDF: deleting pages 1–20 left 25 pages starting at "Page 21", and converting it gave the next 20 images.
  4. Repeat until you run out of pages, keeping each batch in its own folder. Every ZIP numbers its images from page_1.png again, so mixing batches would overwrite files.

Don't use Split PDF for this. It writes one separate PDF per page, so a 45-page document becomes 45 files rather than a few sections. The same Delete PDF Pages method also works when you only want a few pages: list every page you do not want, then convert what is left.

The PNG files are too big

PNG stores every pixel exactly, so the size of the file depends on what is on the page, not on how many words or pages there are. A page of text or a line drawing is small. A page that is a photograph or a scan is mostly noise from PNG's point of view, and it comes out many times larger. The table further down shows what we measured for each kind of page.

The pixel size can't be reduced in this tool, because every page is drawn at the same 2× scale. The way to get smaller files from photographic or scanned pages is to export JPG instead, as the comparison below shows.

The text looks soft or blurry

The converter draws each page at 2× the PDF's own size, which is 144 pixels per inch (an A4 page is 1190 × 1684 px), and there is no option to raise it. In a PDF, text is stored as shapes that stay sharp at any size; in a PNG it has become a fixed grid of pixels. So the image looks right at 100% and gets soft when you enlarge it, and no setting after the fact brings the sharpness back. If you need something that stays sharp when printed or enlarged, keep working from the PDF itself.

I need a transparent background

This tool can't produce one. Every PNG it writes is RGB with no transparency channel, and the page is drawn on white. We tested a page with a 40%-opaque red rectangle on it: the PNG showed solid pale red on white, not a see-through shape. PNG as a format supports transparency, but the conversion doesn't use it.

The conversion shows an error

  • The PDF needs a password. The page says the file is password-protected and offers an Unlock PDF button. Remove the password with Unlock PDF, then convert the unlocked copy.
  • The file is over 20 MB. You get a "file too large" page. Compress PDF can shrink it first.
  • The file is damaged or isn't really a PDF. You get a message saying it doesn't look like a valid PDF. Open it in a PDF viewer to check it, and try exporting it again from the program that made it.

Frequently Asked Questions

Can I convert only some pages of a PDF to PNG?

Yes, by removing the others first. Use Delete PDF Pages and list the pages you don't want, separated by commas, then convert the PDF you get back. The numbers must be listed one by one, because ranges such as 3-10 are not accepted.

Do the numbers in the file names match the PDF's page numbers?

Inside the ZIP, page_1.png is the first page of the PDF you uploaded, page_2.png the second, and so on. If you deleted pages first, the numbering starts again from 1 for the shorter PDF, so page_1.png is then the first page that was left.

Why do single-page downloads have a long ID in the file name?

Each upload is given a unique ID so that files from different people never get mixed up, and the single-page download links keep it as a prefix. The ZIP contains the same images with the plain names page_1.png, page_2.png and so on.
