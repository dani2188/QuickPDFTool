How to Compress a PDF File

{% from "components/byline.html" import byline %} {{ byline(date_published, date_modified) }} {% from "components/open_tool.html" import open_tool %} {{ open_tool("/compress-pdf", "Open the Compress PDF tool") }}

PDF files can grow surprisingly large — especially when they contain high-resolution images, embedded fonts, or dozens of pages. A 20 MB PDF can be impossible to attach to an email and slow to upload to a website. Compressing a PDF reduces its file size while keeping the content readable and intact.

In this guide, you will learn how to compress a PDF file in three simple steps using our free online tool. No software installation is required and your file is processed securely on our server then automatically deleted.

Step 1 – Open the Compress PDF Tool

Go to our Compress PDF tool. You will see a file upload area where you can either click to browse your files or drag and drop your PDF directly onto the page.

The tool accepts standard PDF files. If your document is in another format (such as Word or an image), you will need to convert it to PDF first before compressing.

Step 2 – Choose Your Compression Level

Each level (Low, Medium, High and Extreme) is described on the tool page, so this step is about choosing between them. Start with Medium and only go higher if the result is still too large. For documents made of text and simple graphics, even High looks fine on screen. Keep Extreme for scanned documents and PDFs where colour doesn't matter. The email option forces high compression, so use it when a mail provider rejects the file rather than as a default.

Step 3 – Download Your Compressed PDF

After uploading and selecting your compression level, click the compress button. Processing typically takes a few seconds depending on the file size. Once finished, you will be taken to the results page where you can see:

  • The original file size
  • The compressed file size
  • The percentage reduction achieved

Click the download button to save your compressed PDF to your device. The file will also be automatically deleted from our server after a short period.

Tips for Getting the Best Compression Results

  • PDFs with many images will compress far more than text-only documents. A text-heavy PDF might only reduce by 10–20%, while an image-heavy one can shrink by 80% or more.
  • Already-compressed PDFs (for example a PDF that was previously optimised) will not reduce much further. If your reduction is under 5%, the file was likely already well-optimised.
  • Scanned documents are essentially images and respond very well to compression.

Common Use Cases for PDF Compression

Sending by email: Email providers often reject large attachments. Compressing your PDF to under 5 MB ensures it gets delivered without issues.

Uploading to a website or portal: Many online forms, government portals, and HR systems have strict file size limits. Compression helps you meet these limits without losing your document's content.

Saving storage space: If you archive hundreds of PDFs, compressing them can free up gigabytes of disk space or cloud storage.

Faster sharing: Smaller files transfer more quickly over messaging apps, cloud links, and download links.

When Compression Doesn't Go as Planned

You set a target size and got "couldn't get under"

With a target size, the tool tries the four levels in order, from Low to Extreme, and stops at the first one that gets under your number. If even Extreme is not enough, it gives you the Extreme result anyway and says it could not reach the target. That is the end of what quality settings can do for the file. The result page suggests splitting the document into parts. Split PDF does that, and each part can be compressed on its own. A document with a hard limit on total size, such as a single upload field, may need a different approach, such as removing pages you do not need with Delete PDF Pages.

Everything went grey, including the coloured shapes

Extreme converts the whole document to greyscale, not only its photos. In our test a solid red rectangle drawn in the PDF came out grey. Charts and other coloured drawings lose their colour too, so a legend that says "the red line" stops making sense. If colour carries meaning, use High instead, which keeps colour but lowers the image resolution.

The download is gone when you come back

The compressed file is kept for about ten minutes after you upload and the original for about five. If you leave the processing page and return later, the download link answers "File not ready" and you need to run the file again. The result page's before-and-after sizes also need the original to still be on the server, so after the five minutes they show a dash.

"We couldn't compress this PDF"

The message names two causes: a damaged file or a password-protected one. Open the PDF in a viewer to tell which. If the viewer asks for a password, remove it with Unlock PDF and compress the unlocked copy. If it will not open there either, the file is damaged and you need a fresh copy from whoever made it. If it opens normally and still fails, the message does not tell us why, so we cannot say more from here.

Bookmarks, links and searchable text after compressing

They survive. In our test a three-page PDF with a table of contents, a title, author and clickable web links came out of Medium and of Extreme with all of them intact, and the text was still searchable. That makes compression the safer choice than some other tools on this site when the document's navigation matters. Rotating and watermarking, by comparison, lost the bookmarks in the same kind of test.

Frequently Asked Questions

Will compressing a PDF damage or corrupt my document?

No. Compression works by removing redundant data and downsampling images. Your text, layout, and structure remain intact. The document will still open in any PDF reader.

What if the compressed file is the same size as the original?

This happens when the PDF has already been heavily optimised, or when it contains mostly text with no images. In this case, the original file is already as small as it can be.

Can I compress a PDF that I have already compressed?

You can, but a second pass at the same level is unlikely to help much, since the first pass already did the work. We have not measured this. If the first result is still too large, go back to the original file and choose a stronger level, or use a target size.

Should I compress before or after merging several PDFs?

In most cases after. Compressing the merged file once covers everything and gives you a single before-and-after figure to judge.
