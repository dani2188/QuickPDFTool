Frequently Asked Questions

Do I need an account to use these tools?

No. Every tool here works without signing up — upload a file, process it, download the result.

Is there a file size limit?

Yes, uploads are capped at 20MB across every tool on this page. If your file is larger, compress it first with Compress PDF.

Are my files kept after processing?

No. Uploaded files and generated results are automatically deleted from our server within minutes of processing.

Which tool should I use if I'm not sure?

Each tool's own page explains what it does and links to a full step-by-step guide with an FAQ. If you're working on a specific task rather than a specific format, the guides section covers common situations like preparing a document for email or reducing file size.
