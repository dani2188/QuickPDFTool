How to Unlock a PDF (Remove Password Protection)

A password-protected PDF requires you to enter a password every time you open it. While this is useful for security, it becomes inconvenient when you need to share the document with multiple people, edit it, or archive it in a system that doesn't support password handling. Unlocking the PDF removes the password and makes it freely accessible.

Our free online PDF unlocker removes password protection from any PDF as long as you know the current password. No software installation required.

Step 1 – Open the Unlock PDF Tool

Go to our Unlock PDF tool. You'll see a file upload area. Select your protected PDF by clicking or dragging and dropping it onto the page.

Step 2 – Enter the Current Password

Enter the password that was set on the PDF. This is the password you use to open the document currently. The tool needs this to verify your right to access and modify the file.

Note: This tool is designed for owners of documents who know their own password. It is not a password cracking tool and will not work without the correct password.

Step 3 – Download the Unlocked PDF

Once the password is verified, the tool removes the protection and creates an unlocked version of the PDF. Download it to your device. The new file will open in any PDF viewer without requiring a password.

Tips for Working with Unlocked PDFs

  • Unlock before editing: Most PDF editing tools, including our add text and rotate tools, require an unlocked PDF. Remove the password first if you need to make changes.
  • Unlock before compressing: Our PDF compression tool also requires an unprotected file. Unlock first, then compress.
  • Unlock before merging: When merging PDFs, all files must be unlocked. If one file is protected, unlock it before adding it to the merge.
  • Re-protect after editing: If you unlocked a document to make changes, remember to re-apply password protection after editing if the document still needs to be secured.
  • Archive copies: When archiving documents in a document management system, it may be useful to unlock PDFs so the system can index their contents for search.

Common Reasons to Unlock a PDF

Editing a protected document: You need to make changes to a PDF but can't because it's locked. Unlock it, make your edits, then re-protect if needed.

Printing without restrictions: Some protected PDFs block printing. Unlocking the file restores full print access.

Sharing without requiring a password: You want to distribute a document to a wider audience without needing to communicate the password to each person individually.

Processing in software: Automated systems and document management platforms often cannot process password-protected files. Unlocking allows them to work correctly.

Compressing or merging: PDF manipulation tools generally require unlocked files. Unlock your PDF before using other tools on it.

Can I unlock a PDF that someone else sent me?

Only if you were given the password. If the document was sent to you with a password, you should have received the password separately from the sender.

Will unlocking affect the content of my PDF?

No. Only the password protection layer is removed. All text, images, formatting, and content remain exactly as they were in the original document.
